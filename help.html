GÉANT Terraformator

Help Page

Intro

Terraformator uses consul KV DB to store terraform statuses and VM information
VM configurations and statuses are stored in a hierarchical folder structure
Status files inside the folders are handled by Terraform

Folders structure

  • 1st level: application name. A matching folder on VMware is prefixed with the team name (omitted for Devops team)
  • 2nd level: datacenter location (i.e.: lon, fra, par...)
  • 3rd level: environment (i.e.: test, uat, prod)
  • Last level: keys like variables.tf.json, nsx_tags.json and others

Authentication

Authentication is configured against the Windows Domain GEANT.LOCAL
The users should be added to proper groups on the domain controller
You should use only the username (usually name.surname) without the domain name

NSX-T tags

It's possible to select multiple tags from a list of predefined tags
The tags will be the same for all the VMs within the same folder
At least one tag must be selected
